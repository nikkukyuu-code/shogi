# 将棋 — 歩以外7枚 or 玉取り

ブラウザで動く将棋バリアント（静的SPA）。通常の将棋ルールで指しつつ、**勝ち方が特殊**です。

## 勝利条件（本バリアント）

どちらか先に達成した側の勝ち：

1. **トロフィー7個** — 相手の **歩以外** の駒を累計7枚取る  
   - 数える：と金・香・桂・銀・金・角・飛 および成香・成桂・成銀・馬・龍  
   - 数えない：歩・玉（王）  
   - 取った駒を打ち直してもトロフィーは減りません（取得カウント専用）
2. **玉取り / 詰み** — 王・玉を取る、または詰みにする

## 遊び方

- デフォルトは先手があなた。画面上部が相手、下部があなたの **取得スコアボード**（`取得 n / 7` と7スロット）。
- トロフィー取得時はスロットに駒が入り、数字が金色にパルスします。5〜6枚で赤く強調。
- 勝敗時は全画面演出（「勝ち」「負け」）と理由表示。`alert` は使いません。
- 操作：選択→移動、ドラッグ＆ドロップ、持ち駒打ち、待った、投了、今すぐ指す。

## AIについて

Web Worker 上のカスタム探索エンジンが、**トロフィー競争と玉取り**を評価に組み込んでいます（7個目前の駒得を強く評価）。

思考レベル：初級 / 中級 / 上級 / 真剣。

真剣を選ぶと **ランキング** ボタンが出ます。対局開始から投了までの時間をミリ秒で記録し、**早いほど上位** です（投了時間は送信前に AES-GCM で暗号化し、この端末に暗号文のまま保存。1手以上指してから投了した対局だけ入ります）。
