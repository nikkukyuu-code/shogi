# 7GET将棋 — 歩以外7枚 or 玉取り

ブラウザで動く将棋バリアント（静的SPA）。通常の将棋ルールで指しつつ、勝ち方が特殊です。

## URL

- 説明ページ … https://nikkukyuu-code.github.io/shogi/
- プレイ … https://nikkukyuu-code.github.io/shogi/game/

## レイアウト

- ルートの `index.html` … ルール説明（ゲームロジックなし）
- `game/` … プレイ用本体

## 勝利条件

どちらか先に達成した側の勝ち：

1. **トロフィー7個** — 相手の **歩以外** の駒を累計7枚取る
   - 数える：と金・香・桂・銀・金・角・飛 および成香・成桂・成銀・馬・龍
   - 数えない：歩・玉（王）
   - 取った駒を打ち直してもトロフィーは減りません
2. **玉取り / 詰み** — 王・玉を取る、または詰みにする
